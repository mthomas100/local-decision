# Benchmark images: AI-generated

Every image here is AI-generated or drawn in code; none shows a real person.

- `base-*.jpg`: renders of AI-generated 3D models (treasure chest, robot mailbox, ship lantern,
  apothecary bottle, toaster robot, teddy bear robot), made locally with Z-Image Turbo (Apache-2.0)
  concept images turned into meshes by Hunyuan3D (Tencent Hunyuan community licence); frames from
  AI-generated video clips made with LTX-2.5 (Lightricks model licence: golden retriever,
  lighthouse, ice queen, fashion model); and one Z-Image Turbo concept image (orange cat).
- `render-*.jpg`: those renders with defects added in code (black, missing textures, noise, half cut off, dimmed).
- `count-*.png`: red circles and blue squares drawn in code.

Built by `bench/usecases.py prepare` (`prep_images`).
